1. Коротка інформація про ОС GNU/Linux

Історія створення та природа системи

GNU/Linux — це вільна, багатозадачна та багатокористувацька операційна система сімейства Unix-подібних. Вона виникла в результаті об'єднання двох незалежних проєктів:

  • Проєкт GNU (1983 р., Річард Столлман): створив вільну екосистему системних утиліт, компіляторів (GCC), бібліотек (glibc) та оболонку BASH, але не мав готового ядра.
  • Ядро Linux (1991 р., Лінус Торвальдс): фінський студент створив монолітне ядро для архітектури x86 і поширив його під ліцензією GNU GPL, заповнивши відсутню ланку.

Тому технічно правильно називати повну систему саме GNU/Linux, де Linux є ядром, а GNU — системним оточенням.

Філософія UNIX та Архітектура

В основі Linux лежить перевірена часом філософія UNIX:

«Кожна програма повинна робити одну річ і робити її добре; програми повинні спілкуватися через текстові потоки; все є файлом.»
[Користувацький простір] Web-браузер, BASH, SSH, утиліти
            ▲    │ Системні виклики (POSIX Syscalls)
            │    ▼
[Простір ядра (Kernel)]  Планувальник CPU, Драйвери, Мережа, VFS
            ▲    │ Апаратна взаємодія
            │    ▼
[Hardware]               Процесор, RAM, SSD/NVMe, Мережева карта

2. Перелік найбільш популярних дистрибутивів

Ubuntu APT / Snap

Найпопулярніший дистрибутив на базі Debian від Canonical. Еталон дружності до початківців, потужний вибір для хмарних серверів (AWS, Azure) та AI/ML інженерії.

Девіз: Human-first Реліз: кожні 6 міс / LTS
Debian APT / DPKG

«Універсальна операційна система». Легендарна стабільність, сувора перевірка вільного ПЗ. Є батьківською основою для Ubuntu, Kali, Mint та Pop!_OS.

Сфера: Сервери / Кластери Реліз: Стабільний (2 роки)
Fedora DNF / RPM

Полігон інновацій та передових технологій за підтримки Red Hat. Першим впроваджує Wayland, PipeWire, systemd та свіжі версії ядра Linux.

Сфера: Розробка / RHEL база Реліз: кожні 6 місяців
Arch Linux Pacman / AUR

Дистрибутив за принципом KISS (Keep It Simple, Stupid). Повна персоналізація, встановлення через CLI, безперервні оновлення (Rolling Release) та репозиторій AUR.

Сфера: Досвідчені ентузіасти Реліз: Rolling Release
Linux Mint APT / Flatpak

Ідеальне робоче середовище для користувачів, які переходять з Windows. Оболонка Cinnamon відтворює звичний інтерфейс з пуском і панеллю задач «з коробки».

Сфера: Домашні ПК / Офіс Основа: Ubuntu LTS
Kali Linux APT / Debian-base

Спеціалізована ОС для фахівців з кібербезпеки та тестувальників на проникнення (Penetration Testing). Понад 600 утиліт для аудиту та аналізу захищеності.

Сфера: InfoSec / Аудит Розробник: OffSec

3. Приклади команд роботи в Linux CLI (10 базових утиліт)

Кожен інженер, системний адміністратор та спеціаліст з кібербезпеки починає роботу з командного рядка (CLI). Нижче деталізовано всі 10 обов'язкових команд з практичним синтаксисом:

1. pwd Print Working Directory

Виводить абсолютний шлях до поточного робочого каталогу, у якому ви зараз перебуваєте.

pwd
2. echo Display text / variable

Виводить рядок тексту в консоль або значення системних змінних, а також записує дані у файли через перенаправлення потоку.

echo "Hello Linux" > welcome.txt && echo $USER
3. ls List Directory Contents

Відображає вміст поточної або вказаної директорії. Ключ -l формує детальний список, а -a показує приховані файли.

ls -lah /var/log
4. cd Change Directory

Перехід між директоріями файлової системи. cd .. переходить на рівень вище, а cd ~ повертає у домашній каталог.

cd /etc/nginx/ && cd .. && cd ~
5. touch Create empty file / Update timestamp

Створює новий порожній файл із вказаним розширенням або оновлює мітку часу останнього звернення, якщо файл вже існує.

touch app.log script.sh .env
6. mkdir Make Directory

Створює нові каталоги. Опція -p дозволяє рекурсивно генерувати все дерево вкладених папок, не викликаючи помилки.

mkdir -p ~/projects/cybersec/logs
7. cp Copy Files & Folders

Копіює файли або директорії з джерела в призначення. Для копіювання каталогів обов'язковий прапорець -r (рекурсивно).

cp config.yaml config.yaml.bak && cp -r src/ backup/
8. mv Move / Rename

Переміщує файл чи директорію в інше місце призначення або перейменовує його, якщо шлях залишається незмінним.

mv old_name.txt secure_notes.txt && mv *.log /var/log/backup/
9. rm Remove / Delete

Видаляє файли або папки назавжди (у Linux немає кошика для CLI). -r видаляє рекурсивно, -f вимикає зайві запити підтвердження.

rm temp.txt && rm -rf ./cache_directory/
10. history Command History Buffer

Виводить пронумерований список раніше введених у поточному або попередніх сеансах команд. Дозволяє шукати через grep або повторювати через !номер.

history | tail -n 15 | grep "git"

4. BASH-скрипт: Імітація текстової авторизації в системі

Скрипт відтворює автентичний процес входу до консолі Linux (TTY). Він зчитує ім'я користувача, запитує пароль у закритому режимі без відлуння (як утиліта login/sudo), обмежує кількість спроб до 3 та у разі успіху надає системний звіт про сесію.

bash ~/scripts/sys_login_auth.sh 
#!/usr/bin/env bash
# ==============================================================================
# Лабораторний практикум: Імітація авторизації в текстовому режимі (Linux TTY)
# ==============================================================================

# Конфігурація еталонних облікових даних
VALID_USER="student"
VALID_PASS="cybersec2026"
MAX_ATTEMPTS=3
CURRENT_ATTEMPT=1

# Кольорові коди ANSI для форматування виводу
COLOR_RESET='\033[0m'
COLOR_RED='\033[0;31m'
COLOR_GREEN='\033[0;32m'
COLOR_CYAN='\033[0;36m'
COLOR_YELLOW='\033[1;33m'

clear
echo -e "${COLOR_CYAN}======================================================${COLOR_RESET}"
echo -e "  ДЕМОНСТРАЦІЯ СИСТЕМИ АВТОРИЗАЦІЇ (LINUX TTY 1)"
echo -e "  Ядро: $(uname -s -r) | Хост: $(hostname)"
echo -e "======================================================${COLOR_RESET}"
echo "Увага: Несанкціонований доступ суворо заборонено!"
echo ""

while [ $CURRENT_ATTEMPT -le $MAX_ATTEMPTS ]; do
    echo -e "${COLOR_YELLOW}[Спроба $CURRENT_ATTEMPT з $MAX_ATTEMPTS]${COLOR_RESET}"
    
    # 1. Запит імені користувача
    read -p "Введіть логін: " input_user
    
    # 2. Запит пароля без відображення символів (прапорець -s)
    read -s -p "Введіть пароль: " input_pass
    echo "" # Перенесення рядка після прихованого вводу

    echo -ne "Перевірка підпису PAM модуля..."
    sleep 0.8
    echo " Готово."

    # 3. Валідація облікових даних
    if [[ "$input_user" == "$VALID_USER" && "$input_pass" == "$VALID_PASS" ]]; then
        echo -e "\n${COLOR_GREEN}[+] АВТОРИЗАЦІЯ УСПІШНА! Ласкаво просимо, $input_user.${COLOR_RESET}"
        echo -e "------------------------------------------------------"
        echo -e "Дата останнього входу : $(date '+%Y-%m-%d %H:%M:%S')"
        echo -e "Робочий каталог       : $HOME"
        echo -e "Поточний термінал     : $(tty 2>/dev/null || echo '/dev/pts/0')"
        echo -e "Рівень привілеїв      : Стандартний інженерний доступ (UID 1000)"
        echo -e "------------------------------------------------------\n"
        exit 0
    else
        echo -e "${COLOR_RED}[-] Помилка автентифікації: Невірний логін або пароль!${COLOR_RESET}\n"
        CURRENT_ATTEMPT=$((CURRENT_ATTEMPT + 1))
    fi
done

# Дії у разі вичерпання ліміту спроб
echo -e "${COLOR_RED}======================================================${COLOR_RESET}"
echo -e "${COLOR_RED}[КРИТИЧНО] Досягнуто ліміт невдалих спроб входу ($MAX_ATTEMPTS)!${COLOR_RESET}"
echo -e "Термінал тимчасово заблоковано на 30 секунд. Подію зафіксовано в syslog."
echo -e "${COLOR_RED}======================================================${COLOR_RESET}"
exit 1

Інструкція для запуску на Linux-машині:

# 1. Збережіть код у файл скрипта:
nano auth_test.sh

# 2. Надайте файлу права на виконання:
chmod +x auth_test.sh

# 3. Запустіть скрипт у терміналі:
./auth_test.sh

# (Тестові дані: Логін: student | Пароль: cybersec2026)
